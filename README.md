# Laboratorio de Producto

Herramientas interactivas gratuitas para Product Managers y Product Owners. Incluye priorización $100, matriz impacto/esfuerzo, árbol de oportunidades, Impact Mapping y RACI.

Sitio autónomo en HTML, CSS y JavaScript sin cuentas ni backend. Los ejemplos son ficticios.

Portafolio profesional: https://pedro-navarrete-portfolio.vercel.app/
